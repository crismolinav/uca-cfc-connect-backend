\#  UCA-CFC Connect - Sistema Web Empresarial



Sistema de gestión para el Centro de Formación Continua de la UCA. Proyecto de cátedra para Desarrollo de Software Empresarial enfocado en automatizar inscripciones, cotizaciones, alquiler de espacios y catering.



\##  Tecnologías Principales

\* \*\*Backend:\*\* Java 21, Spring Boot, Spring MVC

\* \*\*Persistencia:\*\* Spring Data JPA, Hibernate, MySQL/PostgreSQL

\* \*\*Seguridad:\*\* Spring Security, JWT

\* \*\*Documentación API:\*\* Springdoc-OpenAPI (Swagger)

\* \*\*Testing:\*\* JUnit 5, Mockito



\##  Estructura del Proyecto (Arquitectura MVC)

\* `controller/`: Exposición de endpoints REST y DTOs.

\* `service/`: Lógica de negocio (validaciones, cruces de horarios).

\* `repository/`: Interfaces JPA para persistencia.

\* `model/`: Entidades de la base de datos.

\* `security/`: Filtros y configuración de JWT.
